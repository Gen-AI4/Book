# Course Roadmap

This roadmap outlines the progression through the Physical AI & Humanoid Robotics curriculum, connecting foundational concepts to advanced implementations.

## Module Overview

The curriculum is structured into six progressive modules, each building upon the previous knowledge:

### Module 1: Foundations (01-intro)
- Physical AI concepts and embodied intelligence
- Hardware lab setup and safety considerations
- Mathematical foundations for robotics

### Module 2: The Nervous System (02-module-1-ros2)
- ROS 2 architecture and communication patterns
- Robot control and sensor integration
- Python agents and autonomous behaviors

### Module 3: Digital Twin (03-module-2-digital-twin)
- Physics simulation with Gazebo
- Unity rendering and visualization
- Sensor simulation and URDF modeling

### Module 4: NVIDIA Isaac Brain (04-module-3-isaac)
- Isaac Sim integration and workflows
- ROS bridge for simulation-to-reality
- Visual SLAM and navigation systems

### Module 5: Vision-Language-Action Models (05-module-4-vla)
- VLA model architectures and implementations
- Voice interface and multimodal interaction
- LLM planning for robotics

### Module 6: Capstone Project (06-capstone)
- Integration of all learned concepts
- Real-world deployment scenarios
- Final demonstration and evaluation

## Learning Pathways

### Academic Pathway (15-Week Semester)
- **Weeks 1-2**: Module 1 - Foundations
- **Weeks 3-5**: Module 2 - ROS 2 and Control
- **Weeks 6-8**: Module 3 - Simulation and Digital Twins
- **Weeks 9-11**: Module 4 - Isaac and Navigation
- **Weeks 12-13**: Module 5 - VLA and Multimodal AI
- **Weeks 14-15**: Module 6 - Capstone Integration

### Professional Pathway (12-Week Intensive)
- **Weeks 1-2**: Modules 1 & 2 (Accelerated)
- **Weeks 3-5**: Modules 3 & 4 (Integrated)
- **Weeks 6-8**: Module 5 (Deep Dive)
- **Weeks 9-12**: Module 6 & Capstone (Project-Based)

> [!hardware]
> **Hardware Timeline**: Physical robot access is recommended starting in Module 2, with intensive hardware use in Modules 3-6. Simulation can substitute for physical hardware through Module 4.

## Prerequisites by Module

### Mathematical Prerequisites
- **Linear Algebra**: Essential for all modules
- **Calculus**: Required for control theory (Modules 2-4)
- **Probability & Statistics**: Needed for perception and learning (Modules 4-5)
- **Differential Equations**: For dynamic systems (Modules 2-4)

### Programming Prerequisites
- **Python**: Required for all modules
- **C++**: Recommended for performance-critical applications (Modules 2-4)
- **ROS 2**: Introduced in Module 2, used throughout
- **Simulation Tools**: Gazebo, Isaac Sim (Modules 3-4)

## Assessment Strategy

### Formative Assessments
- **Weekly Quizzes**: Conceptual understanding
- **Lab Reports**: Practical implementation skills
- **Code Reviews**: Software engineering practices
- **Peer Evaluations**: Collaboration and communication

### Summative Assessments
- **Midterm Project**: Integration of Modules 1-3
- **Final Project**: Complete system from Modules 1-5
- **Capstone Demonstration**: Real-world application (Module 6)

## Technology Stack Integration

Each module introduces and integrates specific technologies:

### Core Stack
- **ROS 2 Jazzy**: Robot communication and control
- **Python 3.9+**: Primary development language
- **C++**: Performance-critical components
- **Docker**: Environment consistency

### Simulation Stack
- **Gazebo Garden**: Physics simulation
- **Isaac Sim**: NVIDIA's robotics simulator
- **Unity**: High-fidelity rendering
- **RViz2**: Visualization

### AI/ML Stack
- **PyTorch**: Deep learning framework
- **TensorRT**: Inference optimization
- **OpenVINO**: Edge AI deployment
- **Transformers**: LLM and VLA models

## Hardware Integration Points

### Simulation-First Approach
- **Modules 1-3**: Primarily simulation-based
- **Modules 4-5**: Simulation with occasional hardware validation
- **Module 6**: Hardware-focused implementation

### Progressive Hardware Exposure
- **Tier 1**: Computational requirements (GPUs, workstations)
- **Tier 2**: Sensor integration (cameras, IMUs, LiDAR)
- **Tier 3**: Full humanoid robot control

- **Embodied AI**: Active research in multimodal learning
- **Humanoid Control**: Cutting-edge research in whole-body control
- **VLA Models**: Emerging research area in robotics

## Career Pathways

Graduates of this curriculum are prepared for roles in:
- Robotics software engineering
- AI/ML engineering for robotics
- Simulation engineering
- Control systems engineering
- Research scientist in embodied AI

## Continuous Learning

The field of Physical AI is rapidly evolving. Students are encouraged to:
- Follow conferences: RSS, ICRA, IROS, CoRL
- Contribute to open-source robotics projects
- Engage with the ROS and NVIDIA developer communities
- Pursue advanced degrees in robotics or AI

## Summary

This roadmap provides a structured path from foundational concepts to advanced implementations in Physical AI and humanoid robotics. The curriculum balances theoretical understanding with practical implementation, preparing students for careers at the intersection of artificial intelligence and physical systems.
